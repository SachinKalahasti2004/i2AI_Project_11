    Limitations

    Small, synthetic, English-only. Results do not establish production safety.

    Small sample

    45 prompts: 9 per domain and 15 per age, so differences between groups may not be significant.

    Improve: grow to many prompts per cell and report confidence intervals.

    Adults imitating children

    Prompts are written by adults, so they may not match how real children phrase things.

    Improve: review prompts with child-development experts and, ethically, with young people.

    Single-turn, text only

    Real conversations build up over many turns, and children also use voice and images.

    Improve: add multi-turn scenarios where risk emerges gradually.

    Judgment-call labels

    Some expected decisions and adults vary by culture, family or setting.

    Improve: use several annotators, report agreement, and keep disputed items flagged.

    Few models

    Only [n] models and one guardrail prompt were tested.

    Improve: add more models and several guardrail wordings.

    Handoff not verified

    The benchmark checks what a model says, not whether an adult is actually reached.

    Improve: pair it with studies of real-world follow-through.

    How to improve the project

    1. Replace mock values with real runsRun every prompt on each model and condition, repeat runs, and load the results into assets/data.js.
    2. Validate the labelsHave independent reviewers label each prompt and compute agreement before trusting the scores.
    3. Expand coverageMore ages (e.g. 7, 12), more languages, and more domain variants per age.
    4. Test the guardrail trade-offCompare several system prompts to find one that cuts under-escalation without a large rise in over-escalation.
    5. Add realismMulti-turn conversations, and prompts informed by how children actually write.
